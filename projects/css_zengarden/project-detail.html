CSS Zen Garden

Two distinct visual identities built from the same HTML structure.

Overview

CSS Zen Garden is a design challenge that demonstrates how much visual variety can be created with CSS alone. For this project, I created two contrasting directions, Classicism and Brutalism, to explore how style, structure, and atmosphere can completely change the same content.

Process

Challenge

The HTML stayed fixed, so the challenge was to create two strong and clearly different design systems without changing the underlying structure.

Approach

I researched both styles and translated them into visual rules. Classicism became balanced, elegant, and refined, while Brutalism became raw, direct, and structural.

Build

I worked directly in the browser using CSS Grid, Flexbox, pseudo-elements, and layout experimentation to shape the page into two very different experiences.

Outcome

The final result shows how concept, typography, spacing, and color can transform a fixed structure into something expressive. It strengthened my CSS craftsmanship and my ability to design with constraints.

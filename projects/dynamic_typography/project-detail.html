Dynamic Typography

Animating words so motion reinforces meaning.

Overview

Dynamic Typography is a group project that explores how animation can add meaning to text. Using only HTML and CSS, we created animated words where the motion supports the idea behind each word instead of distracting from it.

Process

Challenge

The main challenge was to make typography feel expressive and readable at the same time, without relying on images or heavy effects.

Approach

We brainstormed different visual interpretations for each word and matched the animation style to the meaning of the text. The goal was to make each piece feel conceptually connected, not just decorative.

Build

I built the animations with semantic HTML and CSS keyframes, paying attention to timing, motion, and how the letters behave as a system.

Outcome

The final result is a lightweight, playful series of animated type pieces that show how motion can support storytelling. It demonstrates my interest in both interaction design and front-end implementation.
